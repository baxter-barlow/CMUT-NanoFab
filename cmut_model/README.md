# CMUT design-space model

Analytic model behind [`../CMUT_NEUROTECH_RESEARCH.md`](../CMUT_NEUROTECH_RESEARCH.md) (§1, §6.2, §8). It uses small-deflection theory for a clamped circular plate, with residual stress, Lamb fluid loading, and single-mode electrostatic pull-in (Wygant/Kupnik/Khuri-Yakub). A Galerkin reference solution is included. Formula sources are in the docstring of `model/cmut.py`.

Requires `python3` with numpy and scipy. Every script runs from any working directory and writes its outputs next to itself.

| Path | What it does | Output |
|---|---|---|
| `model/cmut.py`, `model/materials.py` | Physics core and material constants | — |
| `model/design_space.py` | Immersed and air design tables, gap scaling, stress, nanogap feasibility | `model/results/*.csv`, `tables.txt`, `recommended.json`, `nanogap_feasibility.json` |
| `model/validate.py` | Compares the model with published devices (Gerardo 2018 polyCMUT, Merbeler 2022) | stdout |
| `designs/nanogap_design.py` | The recommended NanoGap ladder, array and C-V pad numbers | `designs/nanogap_results.{txt,json}` |
| `designs/fus_array.py`, `designs/fus_cell.py` | fUS-slice array and beamforming Monte Carlo (concept B) | `designs/fus_array_results.txt` |
| `designs/optics_and_checks.py` | Thin-film reflectance estimates for the witnesses | `designs/optics_results.txt` |
| `report_checks/baseline.py` | Baseline (1 µm gap) die and cross-checks | stdout |
| `designs/round2_gap_matched_arrays.py` | Round-2 (v2) numbers: three gap-matched array copies, bare-twin offsets, usability Monte Carlo (report §6.12) | `designs/round2_gap_matched_arrays_out.txt` |
| `report_checks/free_capacitance.py` | Static (Q/V) vs free (dQ/dV) capacitance change; the ramp C-V reads the free capacitance (report §6.12 erratum) | stdout |
| `check/` | The independent re-derivation (Hermite FE pull-in, margins) | stdout |

**Note.** Section 11 of `designs/nanogap_results.txt` (the gap-independent stress readout from the bare-cell V_PI ratio) was appended by a separate check script and is not regenerated by `nanogap_design.py`. Re-running the script will drop that section.

**Validity limits** (details in §8 of the report):
- Linear plate theory under-predicts pull-in when deflection exceeds ~0.5 t.
- The capillary-stiction criterion is a heuristic.
- Absolute pull-in voltages were 35–50% off for one published device, so use the scaling laws rather than the absolute values.
